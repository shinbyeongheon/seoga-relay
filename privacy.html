서가 개인정보처리방침

시행일: 2026년 10월 27일

1. 서비스

서가(이하 "서비스")는 사내 업무 앱을 모아 두고 빌려 쓰는 사내 웹 서비스입니다. 이 방침은 서비스가 이용자의 정보를 어떻게 다루는지 설명합니다.

2. 처리하는 정보

  • 서가 계정 정보: 이용자가 입력한 이름, 부서, 대여 기록, 앱 사용 기록(서가 서버에 저장)
  • 구글 연결 시 정보: 이용자가 구글 계정을 연결하면 이메일 주소, 구글 캘린더 일정, 구글 할 일(Tasks) 항목에 접근합니다.

3. 구글 사용자 데이터의 이용

  • 서비스는 이용자가 허용한 범위(calendar.events, tasks, 로그인용 openid·email)에서만 구글 데이터에 접근합니다.
  • 구글 데이터는 이용자 본인의 화면에 일정과 할 일을 보여 주고, 이용자가 요청한 추가·수정·완료·삭제를 구글에 전달하는 목적으로만 사용합니다.
  • 구글 접근 키와 일정·할 일 내용은 서가 서버에 저장되거나 전송되지 않습니다. 이용자의 브라우저가 구글에 직접 연결하며, 접근 키는 해당 브라우저의 저장소에만 보관됩니다.
  • 구글 데이터를 제3자에게 제공·판매하지 않으며, 광고나 이용자 프로파일링에 사용하지 않습니다.
  • 서비스의 구글 API 정보 사용과 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 보관과 삭제

  • 구글 접근 키는 약 1시간 뒤 만료되며, 이용자가 앱의 「연결 해제」를 누르면 구글에 접근 취소를 요청하고 브라우저에 저장된 키를 삭제합니다.
  • 구글 계정의 보안 설정(서드 파티 앱 및 서비스)에서도 언제든 서비스의 접근 권한을 삭제할 수 있습니다.
  • 서가 계정 정보와 대여·사용 기록의 삭제를 원하면 서가 관리자에게 요청하세요.

5. 제3자 제공·위탁

서비스는 이용자 정보를 외부에 제공하거나 처리를 위탁하지 않습니다. 구글 연결 시 이용자의 브라우저가 구글(캘린더·Tasks API)과 직접 통신합니다.

6. 안전성 확보

서가 서버는 사내망에서만 운영되며, 서버에는 구글 접근 키가 도달하지 않습니다. 공용 PC에서 구글을 연결했다면 사용 후 「연결 해제」를 눌러 주세요.
